# Archives scientifiques

Ces documents sont conservés pour rendre les changements de stratégie
auditables. Ils ne décrivent pas l'état actuel du programme.

- [`roadmaps/`](roadmaps/) : anciennes feuilles de route remplacées ;
- [`oracles/`](oracles/) : modèles locaux ou factorisés non transférés à la
  grille complète ;
- [`certificates/`](certificates/) : bornes rigoureuses intermédiaires
  subsumées par le certificat P809439.

Pour la stratégie actuelle, revenir au
[statut canonique](../CURRENT_STATUS.md). Pour comprendre pourquoi une route
a été archivée, consulter l'[index raisonné](../INDEX.md#archives).
